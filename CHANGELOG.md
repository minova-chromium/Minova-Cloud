# Changelog

## 1.2.0

- On this phone gallery with selectable photos and videos.
- Shared phone-file browser and optional Android all-files access.
- More > Phone access for full or selected photo/video access and shared-file access.
- Free up phone space: persistent backup queue, fresh SHA-256 verification, explicit in-app confirmation and Android deletion approval.
- Missing, modified, cancelled or cross-account copies cannot authorize phone removal.
- Reuses verified phone-backup receipts without duplicating known backups.
- Protected cleanup requires Android 11 or newer; normal browsing and uploads retain Android 8+ support.

## 1.1.0

- New Minova header, icons, welcome panel, media shortcuts, and bottom navigation.
- Richer file rows and photo/video cards.
- Grouped account, backup, transfer, and library settings.
- Quieter refreshes preserve the library's scroll position.
- Support for modern Android back gestures.
- Automatic GitHub builds and signed draft releases.

## 1.0.0

- Initial native Android client for Minova Cloud.
- Files, Photos, Videos, sharing, trash/restore, and queued uploads.
- Opt-in photo/video backup and revocable device access.
